```
---

### Feature 2: DETECÇÃO AUTOMÁTICA DE PADRÕES

**Lógica:**
- Sistema processa TODAS as entries do user
- Compara eventos/decisões/emoções
- Identifica repetições (mínimo 3 ocorrências)
- Classifica por tipo e frequência

**Tipos de Padrões:**
1. **Decisional:** "Aceitas projetos quando estás cansada"
2. **Emocional:** "Frustração aparece após reuniões com X"
3. **Relacional:** "Conflitos com pessoas que dão ordens"
4. **Comportamental:** "Procrastinas quando tarefa não tem deadline"

**Confidence Score:**
- 3 ocorrências = 60%
- 5 ocorrências = 80%
- 7+ ocorrências = 95%

**Prompt IA (multi-entry):**
```
Tens acesso a 12 semanas de check-ins desta pessoa.

Identifica PADRÕES REPETITIVOS em:
- Decisões semelhantes
- Gatilhos emocionais recorrentes
- Dinâmicas relacionais
- Auto-sabotagem

Para cada padrão:
- Descreve em 1 frase clara
- Indica frequência estimada
- Lista ocorrências específicas (datas)
- Sugere gatilho mais provável
- Estima custo (tempo/energia/oportunidade)

Formato JSON.

4. MOTOR IA CENTRALIZADO
4.1 Estrutura
Ficheiro: /packages/ai-engine/index.ts

typescript
import Anthropic from '@anthropic-ai/sdk';

export class AIEngine {
  private client: Anthropic;
  
  constructor(apiKey: string) {
    this.client = new Anthropic({ apiKey });
  }
  
  async analyze(
    productId: string,
    promptType: string,
    data: any,
    locale: 'en' | 'pt'
  ) {
    // Load prompt template
    const template = loadPrompt(productId, promptType, locale);
    
    // Execute
    const response = await this.client.messages.create({
      model: 'claude-sonnet-4-20250514',
      max_tokens: 1024,
      messages: [{
        role: 'user',
        content: template(data)
      }]
    });
    
    // Parse and return
    return parseResponse(response, promptType);
  }
}

````typescript
'use client'
import { createContext, useContext, useEffect, useState } from 'react'
import { supabase } from '@/lib/supabase/client'
import type { User } from '@supabase/supabase-js'

const AuthContext = createContext({ user: null, loading: true })

export const AuthProvider = ({ children }: { children: React.ReactNode }) => {
  const [user, setUser] = useState(null)
  const [loading, setLoading] = useState(true)

  useEffect(() => {
    // Get session
    supabase.auth.getSession().then(({ data: { session } }) => {
      setUser(session?.user ?? null)
      setLoading(false)
    })

    // Listen to changes
    const { data: { subscription } } = supabase.auth.onAuthStateChange(
      (_event, session) => {
        setUser(session?.user ?? null)
      }
    )

    return () => subscription.unsubscribe()
  }, [])

  return (
    
      {children}
    
  )
}

export const useAuth = () => useContext(AuthContext)
````

-- User profiles
CREATE TABLE user_profiles (
  id UUID REFERENCES auth.users PRIMARY KEY,
  product_id VARCHAR(50) NOT NULL,
  locale VARCHAR(5) DEFAULT 'en',
  timezone VARCHAR(50),
  created_at TIMESTAMP DEFAULT NOW()
);

-- Subscriptions
CREATE TABLE subscriptions (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES auth.users,
  product_id VARCHAR(50) NOT NULL,
  status VARCHAR(20),
  plan_type VARCHAR(20),
  started_at TIMESTAMP DEFAULT NOW(),
  ends_at TIMESTAMP,
  paypal_subscription_id VARCHAR(100)
);

-- Credits
CREATE TABLE user_credits (
  user_id UUID REFERENCES auth.users,
  product_id VARCHAR(50) NOT NULL,
  credits_remaining INT DEFAULT 0,
  last_purchase TIMESTAMP,
  PRIMARY KEY (user_id, product_id)
);

-- Usage tracking
CREATE TABLE usage_log (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES auth.users,
  product_id VARCHAR(50) NOT NULL,
  action VARCHAR(50),
  credits_consumed INT DEFAULT 1,
  created_at TIMESTAMP DEFAULT NOW()
);

-- Enable RLS
ALTER TABLE user_profiles ENABLE ROW LEVEL SECURITY;
ALTER TABLE subscriptions ENABLE ROW LEVEL SECURITY;
ALTER TABLE user_credits ENABLE ROW LEVEL SECURITY;
ALTER TABLE usage_log ENABLE ROW LEVEL SECURITY;

-- RLS Policies (users only see their own data)
CREATE POLICY "Users can view own profile" ON user_profiles
  FOR SELECT USING (auth.uid() = id);

CREATE POLICY "Users can update own profile" ON user_profiles
  FOR UPDATE USING (auth.uid() = id);
